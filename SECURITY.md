# Security

This is a static, local-first personal tool. Do not submit league exports, player
notes, credentials, tokens, or other private draft data in a public issue.

For a vulnerability in the published application or data pipeline, use GitHub's
private vulnerability reporting feature if it is enabled. Otherwise contact the
repository owner privately before disclosing exploit details.

The project never needs a browser-delivered API key. A change that introduces
one should be treated as a security regression.
